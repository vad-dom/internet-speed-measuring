# Download Speed Measurement

Консольный скрипт на Python для измерения скорости скачивания данных по HTTP/HTTPS.

Выполняется 10 последовательных запросов к указанному URL, полностью скачивается ответ каждого запроса и рассчитывается среднее время запроса, общий объем полученных данных и средняя скорость скачивания.

## Требования

- Python 3.8 или новее (с `pip`)
- Git
- Подключение к интернету

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/vad-dom/internet-speed-measuring.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd internet-speed-measuring
   ```

3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите скрипт, передав URL ресурса для скачивания:

   Быстрая проверка работы скрипта:

   ```bash
   python download_speed.py "https://example.com"
   ```

   Измерение скорости скачивания на примере JPEG-файла размером около 5 MB:

   ```bash
   python download_speed.py "https://pnb-website-bucket.s3.us-east-2.amazonaws.com/samples/images/jpg/sample-image-3840x2160-5mb.jpg"
   ```

Для просмотра справки используйте:

```bash
python download_speed.py --help
```

> **Примечание:** Указанные команды проверены на Windows.
> На Linux и macOS команды могут отличаться, например, для запуска Python может потребоваться команда `python3` вместо `python`:
>
> ```bash
> python3 -m pip install -r requirements.txt
> python3 download_speed.py "https://example.com"
> ```

## Результаты измерения

После выполнения 10 последовательных HTTP/HTTPS-запросов выводится:

- **Всего скачано (MB)** — суммарный объем полученных данных в мегабайтах. 1 MB = 1 000 000 байтов.
- **Среднее время запроса (секунды)** — суммарное время выполнения запросов, разделенное на количество запросов.
- **Скорость скачивания (Мбит/с)** — суммарный объем полученных данных в битах, разделенный на суммарное время выполнения запросов. 1 Мбит = 1 000 000 бит.

### Пример вывода

```text
Всего скачано: 0.100 MB
Среднее время запроса: 0.536 секунд
Скорость скачивания: 0.149 Мбит/с
```

Скорость рассчитывается с учетом времени выполнения HTTP/HTTPS-запросов и зависит от доступности и производительности удаленного сервера, сетевых задержек и размера скачиваемых данных. Результат не следует считать точным измерением максимальной скорости интернет-соединения.

## Технические решения

- **Python вместо Node.js.** Выбран из-за простого и читаемого синтаксиса, удобства последовательного выполнения запросов и наличия необходимых инструментов в стандартной библиотеке.
- **Ограничение HTTP/HTTPS.** Поскольку задача связана со скачиванием данных с удаленного ресурса, для упрощения было решено поддерживать только HTTP- и HTTPS-адреса. Возможно расширение функциональности при уточнении требований к поддерживаемым протоколам.
- **Чтение данных блоками по 64 КиБ.** Позволяет обрабатывать ответы большого размера без необходимости целиком загружать их в оперативную память.
- **Измерение времени через `time.perf_counter()`.** Этот таймер предназначен для измерения длительности операций и не зависит от изменений системного времени.
- **Единицы измерения — MB и Мбит/с (Mbps).** Объем данных выводится в мегабайтах, а скорость — в привычных для интернет-соединений мегабитах в секунду, что, например, упрощает сравнение с тарифами провайдеров. Используются десятичные единицы измерения.
- **Проверка HTTPS-сертификатов через `certifi`.** Выбрана для переносимости между ОС и разными окружениями: библиотека предоставляет единый набор доверенных корневых сертификатов независимо от системного хранилища. Альтернатива — использование системных сертификатов, но их доступность зависит от окружения.
